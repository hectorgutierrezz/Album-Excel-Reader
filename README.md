This is an app to check and filter out an album excel that Ive been doing for a while. Its got 2 different front-end options:
    -Terminal based
    -GUI based
    
For the terminal based, you need to execute the following command: "python3 readerTerminal.py"
For the GUI option, the command to execute is: "python3 readerUI.py"

Obviously you need to have python installed in your OS for this to be executed.
